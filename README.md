# Unit and Tenant Management System

[เปิดเว็บต้นแบบบน GitHub Pages](https://title5656.github.io/Software-Engineering-Project/#/home)

โครงการนี้เป็นระบบบริหารจัดการห้องชุดและผู้เช่าในคอนโดมิเนียม เว็บต้นแบบ **Salaya Two Resident** ใช้ข้อมูลจำลองให้ทดลองขั้นตอนตาม Use Case ของโครงการ ตั้งแต่จัดการห้องชุด ผู้พัก และสัญญาเช่า ไปจนถึงแจ้งซ่อม ชำระค่าใช้จ่าย จองส่วนกลาง รับพัสดุ และอ่านประกาศ

จุดที่เห็นได้ชัดในเดโมคือการส่งต่องานระหว่างบทบาท เช่น ผู้พักแจ้งซ่อม นิติบุคคลมอบหมายงาน ช่างบันทึกผล แล้วผู้พักกลับมาติดตามงานรายการเดิมได้

## เริ่มใช้งาน

1. เปิดเว็บต้นแบบแล้วกด **เข้าสู่ระบบ** กรอกชื่อบัญชีตามบทบาทในตารางและรหัสผ่าน `demo123`
2. เปิดเมนูตามงานที่ต้องการทดลอง หากขั้นตอนถัดไปเป็นหน้าที่ของอีกฝ่าย ให้กด **สลับบทบาท** → **เข้าสู่ระบบด้วยบัญชีอื่น** แล้วกรอกข้อมูลของบัญชีนั้น
3. ใช้เบราว์เซอร์เดิมเพื่อดูข้อมูลที่บันทึกไว้หลังรีเฟรช เมื่อต้องการเริ่มใหม่ ให้กด **คืนค่าข้อมูลเดโม** ข้อมูลที่แก้ไว้จะถูกแทนด้วยข้อมูลตัวอย่างเริ่มต้น

| บทบาท | บัญชีเดโม | งานที่ทดลองได้ |
| --- | --- | --- |
| ผู้พักอาศัย | `resident`, `resident2` | ดูสัญญาและขอต่อสัญญา แจ้งซ่อมและติดตามผล ส่งหลักฐานชำระเงิน จองส่วนกลาง ดูพัสดุและประกาศ |
| นิติบุคคล | `office` | จัดการห้องชุด ผู้พัก และสัญญา บันทึกย้ายเข้า–ออก มอบหมายงานซ่อม ตรวจหลักฐานและออกใบเสร็จ จัดการผู้มาติดต่อ พัสดุ ประกาศ และบัญชีผู้ใช้ รวมถึงดูภาพรวมและรายงาน |
| ช่างซ่อม | `tech`, `tech2` | เปิดงานที่ได้รับมอบหมาย อัปเดตความคืบหน้า บันทึกผลซ่อม และปรับสถานะสิ่งอำนวยความสะดวกหลังซ่อม |

หากต้องการทดลองสมัครบัญชีใหม่ ให้กด **เข้าสู่ระบบ** → **ลงทะเบียนผู้พักอาศัย** ใช้ชื่อ **มาร์ก ซักเคอร์เบิร์ก**, เบอร์ **0800000003** และห้อง **A-602** แล้วตั้งชื่อผู้ใช้และรหัสผ่าน เมื่อสร้างบัญชีสำเร็จ ให้กรอกรหัสผ่านเพื่อเข้าสู่ระบบ

## ลองสาธิตตาม Use Case

| Use Case | ขั้นตอนบนเว็บ | สิ่งที่ควรเห็น |
| --- | --- | --- |
| **TC-02 ต่อสัญญาเช่า** | ผู้พักเปิด **สัญญาเช่า** แล้วขอต่อสัญญา → นิติบุคคลพิจารณาคำขอ → ผู้พักกลับมาดูผล | เมื่ออนุมัติ วันสิ้นสุดสัญญาจะเปลี่ยนตามคำขอ หากปฏิเสธ ผู้พักจะเห็นผลและวันสิ้นสุดเดิม |
| **TC-03 แจ้งซ่อม** | ผู้พักเปิด **งานซ่อม** แล้วแจ้งปัญหา → นิติบุคคลมอบหมายงานให้ `tech` → ช่างเปิดงานและบันทึกผล → ผู้พักกลับมาติดตาม | ผู้พักเห็นสถานะ **เสร็จแล้ว** และผลซ่อม บัญชี `tech2` เปิดได้เฉพาะงานที่มอบหมายให้บัญชีของตน |
| **TC-05 ชำระค่าใช้จ่าย** | นิติบุคคลเปิด **การเงิน** แล้วออกใบแจ้งหนี้ → ผู้พักส่งสลิปตัวอย่าง → นิติบุคคลตรวจหลักฐานและออกใบเสร็จเมื่อผ่าน → ผู้พักกลับมาเปิดบิล | ผู้พักเห็นยอดค้างและใบเสร็จ หากหลักฐานไม่ผ่าน ผู้พักจะเห็นเหตุผลที่นิติบุคคลระบุ |

ชื่อบุคคลและรายการในเดโมเป็นข้อมูลสมมติ ใช้รูปแจ้งซ่อม สลิป และใบเสร็จตัวอย่างที่มีในเว็บได้เลย
