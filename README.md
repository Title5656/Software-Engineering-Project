# บ้านร่วม · เว็บต้นแบบระบบบริหารจัดการห้องชุดและผู้เช่า

[เปิดเว็บต้นแบบ](https://title5656.github.io/Software-Engineering-Project/)

เลือก **ผู้พักอาศัย**, **นิติบุคคล** หรือ **ช่างซ่อม** ที่หน้าแรก จากนั้นใช้ปุ่ม **สลับบทบาท** ด้านบนเพื่อดูงานที่ส่งต่อจากอีกบัญชี ข้อมูลจำลองจะอยู่ในเบราว์เซอร์เดิมหลังรีเฟรช ใช้ **คืนค่าข้อมูลเดโม** เพื่อกลับไปเริ่มใหม่

| บทบาท | ชื่อผู้ใช้ |
| --- | --- |
| นิติบุคคล | `office` |
| ผู้พักอาศัย | `resident` หรือ `resident2` |
| ช่างซ่อม | `tech` หรือ `tech2` |

ทุกบัญชีใช้รหัสผ่านตัวอย่าง `demo123` สำหรับลองลงทะเบียน ใช้ทะเบียนผู้พัก **ธารา ตัวอย่าง**, เบอร์ **0800000003**, ห้อง **A-602** แล้วตั้งชื่อผู้ใช้ใหม่ ระบบเก็บข้อมูลและจำลองสิทธิ์ในเบราว์เซอร์ รูปแจ้งซ่อม สลิป และใบเสร็จเป็นตัวอย่างที่มากับเว็บ

## เปิดจากเครื่องและทดสอบซ้ำ

เสิร์ฟโฟลเดอร์ `docs` ผ่าน HTTP เช่น `python -m http.server 8000 --directory docs` แล้วเปิด [localhost](http://localhost:8000/)

```sh
node --test tests/model.test.mjs
```

ชุดทดสอบเบราว์เซอร์ใช้ Playwright และ Chromium หากมี Playwright แล้ว ให้รัน `node tests/browser.mjs` หรือส่ง URL ของเว็บเป็นอาร์กิวเมนต์เพื่อทดสอบเว็บที่เผยแพร่แล้ว ตั้ง `DEMO_PLAYWRIGHT` และ `DEMO_BROWSER` เพื่อระบุพาธของ Playwright และ Chromium ที่ติดตั้งอยู่ได้
